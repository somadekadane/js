A linguaguem JS é case sentive (faz diferença entre letras maiúsculas e minúsculas)
- No JS o ; é opcional
- Você pode usar "" ou '' não é permitdo mistura "' '"
Dica: Usar "textos" e "importações"

Variáveis na linguagem JS são dinâmocamente tipadas
- String
- Number
- Boolean
- Function
- Object

Para crair uma constante usamos: const
para criar um avariavel podemos usar var ou let
var (obsoletp e inseguro(redeclarar a variável))
